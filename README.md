# CanSat Ground Station UI

A web-based Ground Station interface prototype designed for monitoring and controlling a CanSat during mission simulation.

This project demonstrates telemetry visualization, command panel interaction, and 3D orientation rendering in a single-page web application.

---

## Features

- Mission status panel
- Telemetry display (Altitude, Temperature, Pressure, GPS)
- Battery monitoring
- Real-time plot placeholders
- 3D orientation viewer (interactive)
- Command simulation panel
- Clean responsive layout

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Web-based 3D rendering
- VS Code + Live Server

---

## Project Purpose

This UI prototype was developed as part of a CanSat Ground Station system to simulate mission monitoring before backend and telemetry integration.

Currently:
- No backend
- No real telemetry input
- Static placeholders for data visualization

Future integration will include:
- MQTT or serial telemetry input
- Real-time sensor data plotting
- Backend communication layer

---

## System Overview

The interface is divided into:

- Status Panel (mission state & system checks)
- Telemetry Section (sensor values)
- Plot Section (mission graphs)
- 3D View (orientation representation)
- Command Panel (simulation controls)
